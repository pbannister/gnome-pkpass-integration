# Feature Index

- `01-site-build.md` — Site Build: generates `site.out/` from `site.in/`.
- `02-project-pages.md` — Project Pages: the standard published page set (status, dashboard, condensed todo/prompts/documents).
- `03-pkpass-reader.md` — PKPASS Reader: reads the container, the pass, the manifest, and the signature.
- `04-pass-renderer.md` — Pass Renderer: draws a pass as a standalone SVG card.
- `05-pkpass-handler.md` — PKPASS Handler: registers the two Wallet MIME types with the GNOME desktop.
- `06-command-line-tools.md` — Command-Line Tools: `pkpass-inspect`, `pkpass-render`, and `pkpass-integrate`.

- `01-site-build.md` and `02-project-pages.md` are shared with the skeleton and
  are kept for the published page set.
- Features `03` through `06` implement this project's stated purpose.
- Every top-level requirement carries a stable `<FEATURE-NAME>-R<NNN>`
  identifier, and the tasks in `prompts/tasks/` claim those identifiers in
  `TASK-ACCEPTANCE`.
